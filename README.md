# 📚 Sistema de Gestión de Notas de Estudiantes

Aplicación web desarrollada como práctica de JavaScript para registrar estudiantes, almacenar sus calificaciones y generar estadísticas del curso de forma automática.

## 📖 Descripción

Este proyecto permite ingresar la información de hasta **10 estudiantes**, registrar sus tres calificaciones y calcular diferentes métricas académicas, como promedios individuales, promedio general del curso y cantidad de estudiantes aprobados o reprobados.

El objetivo principal es reforzar el uso de estructuras de datos, funciones, manipulación del DOM y métodos de arreglos en JavaScript.

---

## ✨ Funcionalidades

* Registrar estudiantes mediante un formulario.
* Validar que todos los campos estén completos.
* Validar que las calificaciones estén entre **0 y 100**.
* Limitar el registro a un máximo de **10 estudiantes**.
* Calcular el promedio individual de cada estudiante.
* Calcular el promedio de cada certamen.
* Calcular el promedio general del curso.
* Contar estudiantes aprobados y reprobados.
* Ordenar estudiantes según su promedio de mayor a menor.
* Mostrar todos los resultados dinámicamente en la página.

## 🚀 Cómo ejecutar el proyecto

1. Clona este repositorio.

```bash
git clone https://github.com/manuelisaaccamanidiaz-lgtm/manejo_de_notas_de_estudiantes.git
```

2. Abre la carpeta del proyecto.

3. Ejecuta el archivo `index.html` en tu navegador.

4. Ingresa los datos de los estudiantes y utiliza el botón **"Mostrar Resultados"** para visualizar las estadísticas generadas.
